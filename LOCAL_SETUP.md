# Local Windows setup

## Primary workflow: uv

Use `pyproject.toml` to declare dependencies and `uv.lock` to record resolved
versions. The requirements/*.txt files below are retained for reference;
use uv for future dependency changes.

This configuration targets Windows x64 and Python 3.9, with PyTorch CUDA 12.1.
The lock file is generated by uv; do not edit it manually.

```powershell
uv sync --locked --python .venv/Scripts/python.exe
uv run --locked python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
uv tree
```

Add or remove a direct dependency:

```powershell
uv add PACKAGE_NAME
uv remove PACKAGE_NAME
```

These commands update pyproject.toml, uv.lock, and the environment. If editing
pyproject.toml manually, run `uv lock` then `uv sync`. Keep both project files
in Git. Creating a lock does not install the packages or validate training.

## Previous pip workflow (reference only)

Open this repository folder in VS Code. Use `.venv/Scripts/python.exe`.
The original `requirements.txt` is retained as the author's reference.
The files in `requirements/` describe the local installation.

## Install

Run from the repository root in PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements/cuda121.txt
.\.venv\Scripts\python.exe -m pip install -r requirements/windows.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
```

## Track installed versions

After installation succeeds, save all installed packages:

```powershell
.\.venv\Scripts\python.exe -m pip freeze | Out-File -Encoding ascii requirements/lock-windows-py39.txt
```

This file is a snapshot, not a live inventory. Regenerate it after intentional
dependency changes. Update windows.txt or cuda121.txt for new direct dependencies.
To inspect the current environment, run:

```powershell
.\.venv\Scripts\python.exe -m pip list
```

To recreate the saved environment, install cuda121.txt first, then:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements/lock-windows-py39.txt
```

## Data and results

Keep original downloaded data in the workspace's `Data/ViSpeech/` folder.
The repository's dataset/*.txt files contain relative audio paths; make those
paths resolve before training. Note that downloaded data currently has a
`noisy_testset` folder, while the author documents `noise_testset`; check the
paths in the text manifests before copying or linking data.

Keep dataset/*.txt as the original experiment splits.
Training writes to checkpoints/; inference writes to inference_result/.
Record experiment settings and metrics under logs/ when running experiments.
The environment and generated artifacts are excluded from Git.

The default training configuration uses 300 epochs. Start with one epoch and
batch size 4 to check the pipeline on the 4 GB GPU. Windows multiprocessing
may require code changes; dependency installation alone does not verify training.
